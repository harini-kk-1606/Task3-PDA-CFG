FORMAL MODEL

CFG productions

S → (S)S
S → ε

PDA idea

Push a marker for each opening parenthesis. Pop one marker for each closing parenthesis. Accept when the input ends and only the bottom marker remains.

Language

L = { w ∈ {(,)}* | w is balanced }

Model notes

  • Uses an unbounded stack.
  • Order of closing symbols matters.
  • Empty string is accepted.
02 / THE CONCEPTS

Why a stack matters

Context-free languages need more memory than a finite automaton can provide in general.

G
CONTEXT-FREE GRAMMAR

Rules that generate strings

A CFG is a four-tuple G = (V, Σ, P, S). Productions describe how a start symbol can generate valid strings in a language.

S → aSb | ε
Example: strings aⁿbⁿ
⊙
PUSHDOWN AUTOMATON

A finite control + stack

A PDA extends a finite automaton with a stack. It can remember an unbounded number of nested or pending symbols.

δ(q, a, X) = (p, γ)
Read input, inspect and update stack
⇄
CFG ↔ PDA

Two views of a language

Every context-free language can be described by a CFG and recognized by some nondeterministic PDA.

CFG ⇔ NPDA
